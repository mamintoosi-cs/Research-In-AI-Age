## این ارائه دربارهٔ چیست

- **نشست ۱ — مبانی و آموزش:** هوش مصنوعی مولد چیست، مدل‌ها و بنچمارک‌ها، تولید تصویر و ویدئو، عامل‌های هوش مصنوعی (چرخهٔ کار، سطوح خودمختاری، خطرها و مهارها)، مهندسی پرامپت، و پیامدهای آن برای آموزش: بازطراحی تکلیف، دتکتورها و سیاست کلاس.
- **نشست ۲ — پژوهش:** چرخهٔ پژوهش با کمک هوش مصنوعی، جستجوی ادبیات و پژوهش عمیق، عدم قطعیت و منابع ساختگی، مطالعهٔ موردی از مخزن کد تا پیش‌نویس مقاله، و ملاحظات اخلاقی و سیاست ناشران.

مخاطب ارائه، استادان و پژوهشگران دانشگاه هستند؛ نمونه‌ها بیشتر از حوزهٔ علوم کامپیوتر گرفته شده‌اند.

## ساختار مخزن

| مسیر | توضیح |
| --- | --- |
| `index.md` | **منبع اصلی اسلایدها** (Marp، فارسی و راست‌به‌چپ) |
| `build/index.html` | خروجی HTML که روی GitHub Pages منتشر می‌شود |
| `production.md` | دستورهای ساخت HTML، PDF و PPTX و نکات چیدمان اسلایدها |
| `img/` | تصاویر و ویدئوهای اسلایدها |
| `docs/` | فایل‌های جانبی؛ در CI به `build/docs/` تبدیل می‌شوند |
| `.github/workflows/marp-to-pages.yml` | ساخت و انتشار خودکار روی شاخهٔ `gh-pages` |

## ساخت خروجی

```bash
npx --yes @marp-team/marp-cli@3.0.2 index.md --html -o build/index.html
```

پیش‌نمایش هنگام ویرایش، ساخت PDF/PPTX و توضیح چیدمان: [production.md](production.md).

> نسخهٔ marp-cli عمداً روی `3.0.2` ثابت شده است؛ همان نسخه‌ای که در CI استفاده می‌شود. نسخه‌های دیگر می‌توانند چیدمان اسلایدها را جابه‌جا کنند.
